% gradient, the glossary and the settled cross-book decisions.

% Digits are ASCII 0-9 on purpose, here and in the prose, so that a number in
% a sentence matches the same number in the mathematics beside it.
%
% These \omname* strings are INDEFINITE, because they are the environment
% headings ("مبرهنة 3.1"). Arabic wants the definite article when the same
% name is used to refer back to a numbered statement ("حسب المبرهنة 3.1"),
% so onemath.sty overrides the \crefname declarations for Arabic with the
% definite forms. Do not add the article here.
% ============================================================================
